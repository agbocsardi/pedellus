# Durable — app

The installable web app (PWA) that is the chat channel of the Durable agent
gateway. Vite + TypeScript + React 19, Streamdown for streaming markdown,
`vite-plugin-pwa` (injectManifest) for the service worker, `idb` for IndexedDB.
The wire contract is [`../protocol/v2.md`](../protocol/v2.md); the app imports
its types from [`../protocol/v2.ts`](../protocol/v2.ts). HTTP and WebSocket
paths still start with `/v1`.

## Development

Two terminals (the mock prints a single-use pairing code; enter it in the
app's first-run screen):

```sh
npm run mock   # dev mock gateway on 127.0.0.1:8791
npm run dev    # vite on http://localhost:5173, proxying /v1 (incl. ws) to it
```

`npm run mock` accepts an explicit code as an argument (`node
dev/mock-gateway.mjs MYC2DE23`). For a different mock port, set `PORT` on the
mock and the same value as `MOCK_PORT` on Vite (dev or preview). Mock credentials,
threads and cursors are in memory; after a mock restart use a fresh browser
profile or clear site data before pairing again. Set `IDLE_ARCHIVE_MS=3000`
on the mock to try automatic archiving after three seconds of idleness.
The mock shows fork history by copying messages through the selected message;
it doesn't run a real agent.

The production build, incl. the service worker and its precache manifest:

```sh
npm run build    # also runs tsc --noEmit for app and sw
npm run preview  # serves dist/ on http://localhost:4173, same /v1 proxy
```

## Build output

`vite build` writes the complete app to `app/dist/` — `index.html`,
`manifest.webmanifest`, `sw.js`, `registerSW.js`, hashed assets and the icons.
The gateway serves this directory statically from a configured absolute path
on the same origin as `/v1` (behind `tailscale serve`), so app and API share
one origin and one cookie jar.

## Notes

- Icons are generated by `npm run icons` (`scripts/gen-icons.mjs`, no
  dependencies) into `public/icons/`; the apple-touch-icon is opaque on
  purpose.
- The service worker precaches the app shell only; the phase 2 Web Push
  handler has a marked spot in `src/sw.ts` and is deliberately not implemented.
- The store (`src/store.ts`) is a cache: IndexedDB loss means a full replay
  on the next `hello`, nothing more.
